# Legal and project boundaries

Cross Road Native is an unofficial preservation, research, tooling, and modding project. It is not affiliated with or endorsed by Disney, Square Enix, or other rights holders.

## What this repository distributes

This repository may distribute original project code, documentation, metadata, verification hashes, patch descriptions, and independently authored tooling.

## What this repository does not distribute

Do not commit or publish:

- Original KHUX/Dark Road IPA files.
- Original game executables or decrypted Mach-O binaries.
- OBB/data containers or renamed copies of them.
- Original movies, music, artwork, textures, or other game assets.
- Signing credentials, provisioning profiles, Apple IDs, passwords, or device secrets.

Users are responsible for supplying compatible game files and for complying with applicable law and platform terms.

## Patches and mods

Patches and mods should contain only the minimum independently authored data needed to transform a user-supplied compatible input locally. Avoid including substantial original game content in a patch.
