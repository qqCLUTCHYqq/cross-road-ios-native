# Troubleshooting

- No iPhone: connect USB, unlock it, accept Trust, and check connection again.
- Wi-Fi unavailable: unlock the phone and use the same reachable local network.
  Guest networks may isolate devices. A USB connection can restore initial trust.
- Apple sign-in limited: wait for the displayed cooldown before retrying.
- Refresh needs attention: keep Windows signed in, check the phone connection,
  and use Refresh Now. Do not uninstall the game to fix refresh; that may erase saves.
- Secure preparation fails: check the PC clock and network. Do not disable TLS
  verification, Defender, or certificate protection.

Use the GUI's diagnostics export. Review it before sharing. Do not post raw profiles,
Apple credentials/2FA, signing material, game files, device identifiers, saves,
or unreviewed logs. Provide the version, generic error/stage, timestamp, and
whether the connection was USB or Wi-Fi.

Existing saves are preserved by the validated refresh workflow. This repository
has no implemented automatic save-import or game-uninstall feature to advertise.
